“函数”若无特殊说明，则均指普通函数，`function` 类表示的函数，lambda 函数（匿名函数，C++11）或仿函数。

数组可看作一种容器，指针可看作数组的迭代器。

## `algorithm` 库

### 排列类

#### `next_permutation`

作用：重置容器为此容器的下一个排列。

调用方法：`next_permutation(begin, end, cmp)`，其中 `begin` 为容器头迭代器，`end` 为尾迭代器，`cmp` 表示比较方法（当容器中值的数据类型已定义运算符 `<` 时可省略）。

返回值：`true` 表示有下一个排列，`false` 则表示没有。

#### `prev_permutation`

作用：重置容器为此容器的上一个排列。

调用方法：与 `next_permutation` 相似。

返回值：`true` 表示有上一个排列，`false` 则表示没有。

### 排序类

#### `sort`

作用：对容器进行快速排序 **（此快速排序非彼快速排序）**。

调用方法：`sort(begin, end, cmp)`，其中 `begin` 为容器头迭代器，`end` 为尾迭代器，`cmp` 表示比较方法（当容器中值的数据类型已定义运算符 `<` 时可省略）。

提示：当数据量大时它会使用快速排序，分段归并排序；若分段后数据量小于某个阈值（可能为 $16$），便会使用插入排序以防止递归层数过深；若递归层数极深，还会使用堆排序。

比较方法：一个函数，如下所示。

```cpp
bool cmp(Type x, Type y) {
	return x < y;
}
```

这个函数有两个参数，表示两个需要比较的值；返回值为 `true` 时表示 $x < y$，`false` 则表示 $x > y$。

返回值：无返回值。

#### `stable_sort`

作用：对容器进行稳定的排序（底层实现可能为归并排序。稳定的排序：指排序过程中保留相等的值之间的顺序，不会调整）。

调用方法、比较方法：与 `sort` 类似。

返回值：无返回值。

#### `partial_sort`

作用：对容器前 $N$ 小的数进行排序并置于最前，其余数位置不定。

调用方法：`partial_sort(begin, sort_end, end, cmp)`，其中 `begin` 为数列头迭代器，`sort_end` 为 **需要排序的容器** 的尾迭代器，`end` 为 **容器** 尾迭代器，`cmp` 表示比较方法（当容器中值的数据类型已定义运算符 `<` 时可省略）。

比较方法：与 `sort` 类似。

返回值：无返回值。

为了辅助理解，这里有一个程序：

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
	vector<int> v = {7, 3, 9, 1, 6, 2, 8, 5, 4};
	partial_sort(v.begin(), v.begin() + 5, v.end());
	for (int i : v)
		cout << i << ' ';
	return 0;
}
```

输出：`1 2 3 4 5 9 8 7 6`

`partial_sort` 函数对 `v` 的前 $5$ 小的数排序，并置于最前（`1 2 3 4 5`），剩下的数则位置不定（`9 8 7 6`）。

#### `nth_element`

作用：将第 $N$ 小的值设为容器的第 $N$ 项，同时使它左侧的值都小于它（顺序不定），右侧的值都大于它（顺序不定）。

调用方法：`nth_element(begin, end, nth)`，其中 `begin` 为容器头迭代器，`end` 为尾迭代器，`nth` 为指向数组第 $N$ 小的值的迭代器。

返回值：无返回值。

#### `is_sorted`（C++11）

作用：检查容器是否按非降序排列（使用运算符 `<`）。

调用方法：`is_sorted(begin, end, cmp)`，其中 `begin` 为容器头迭代器，`end` 为尾迭代器，`cmp` 表示比较方法（当容器中值的数据类型已定义运算符 `<` 时可省略）。

返回值：如果容器按非降序排列则返回 `true`，否则返回 `false`。

### 查找与统计类

#### `find`

作用：运用顺序查找算法来找到某个值在容器中所在的位置。

调用方法：`find(begin, end, value)`，其中 `begin` 为容器头迭代器，`end` 为尾迭代器，`value` 为需要查找的值。

提示：使用时需要时 `value` 的数据类型必须已定义运算符 `==`。

返回值：找到时返回指向 `value` 所在位置的迭代器，否则返回 `end`。

#### `find_if` 与  `find_if_not`

##### `find_if`

作用：运用顺序查找算法找到某个值在容器中所在的位置（使用自定义比较方法）。

调用方法：`find_if(begin, end, cmp)`，其中 `begin` 为容器头迭代器，`end` 为尾迭代器，`cmp` 为比较方法。

比较方法：一个函数，当返回值为 `true` 时表示当前遍历到的值与某个值相等，`false` 则表示不相等。

返回值：找到时返回指向满足 `cmp` 条件的值所在位置的迭代器，否则返回 `end`。

##### `find_if_not`（C++11）

作用、调用方法、提示、返回值：与 `find_if` 类似。

比较方法：一个函数，当返回值为 `false` 时表示当前遍历到的值与某个值相等，`true` 则表示不相等。（内部实现为对 `cmp` 函数的返回值取反，这个句子只是其形式化表现。）

#### `mismatch`

作用：查找出两个容器中第一个不匹配（即位置相同但值不同）的值。

调用方法：`mismatch(begin_1, end_1, begin_2, cmp)`，其中 `begin_1` 为第一个容器的头迭代器，`end_1` 为尾迭代器，`begin_2` 为第二个容器的头迭代器，`cmp` 为比较方法（当 `value` 的数据类型已定义运算符 `==` 时可省略）。

比较方法：一个函数，当返回值为 `true` 时表示当前两个值相等，`false` 则表示不相等。

返回值：一个 `pair`，`first` 与 `second` 项分别为第一个容器指向不匹配值所在位置的迭代器（与 `begin_1` 数据类型一致）与第二个容器指向不匹配值所在位置的迭代器（与 `begin_2` 数据类型一致）。

#### `adjacent_find`

作用：查找出容器中第一对相邻且相同的值。

调用方法：`adjacent_find(begin, end)`，其中 `begin` 为容器头迭代器，`end` 为尾迭代器。

返回值：找到时返回这个值，否则返回 `end`。

#### `search`、`search_n` 与 `find_end`

##### `search`

作用：在容器中搜索另一个容器中的内容第一次出现在该容器的位置。

调用方法：`search(begin, end, s_begin, s_end, cmp)`，其中 `begin` 为被搜索容器的头迭代器，`end` 为尾迭代器，`s_begin` 为要搜索的容器的头迭代器，`s_end` 为尾迭代器，`cmp` 为比较方法（当容器中值的数据类型已定义运算符 `==` 时可省略）。

返回值：找到时指向要搜索的容器的内容在容器中第一次出现的位置的迭代器，否则返回 `end`。

##### `search_n`

作用：在容器中搜索连续 $cnt$ 个 $n$ 第一次出现在该容器的位置。

调用方法：`search_n(begin, end, cnt, n, cmp)`，其中 `begin` 为被搜索容器的头迭代器，`end` 为尾迭代器，`cnt` 为连续的个数，`n` 为要连续的值，`cmp` 为比较方法（当容器中值的数据类型已定义运算符 `==` 时可省略）。

返回值：找到时返回指向连续 $cnt$ 个 $n$ 在容器中第一次出现的位置的迭代器，否则返回 `end`。

##### `find_end`

作用：在容器中搜索另一个容器中的内容最后一次出现在该容器的位置。

调用方法：与 `search` 类似。

返回值：找到时返回指向要搜索的容器的内容在容器中最后一次出现的位置的迭代器，否则返回 `end`。

#### `find_first_of`

作用：搜索容器中是否存在另一个容器里的任何值。

调用方法：与 `search` 类似。

返回值：找到时返回指向容器中第一个与另一个容器任何值相等的值的迭代器，否则返回 `end`。

#### `binary_search`、`lower_bound` 与 `upper_bound`

#### `binary_search`

作用：运用二分查找算法找出某个值在容器中是否存在。

调用方法：`binary_search(begin, end, value, cmp)`，其中 `begin` 为容器头迭代器，`end` 为尾迭代器，`value` 为需要查找的值，`cmp` 为比较方法（当 `value` 的数据类型已定义运算符 `<` 时可省略）。

比较方法：与 `sort` 类似。

提示：使用时需保证容器已排好序，且 `cmp` 与容器规律（比如升序，降序等）一致。

返回值：找到时返回 `true`，否则返回 `false`。

#### `lower_bound`

作用：查找第一个不小于某个值的位置。

调用方法、提示：与 `binary_search` 类似。

返回值：找到时返回指向第一个不小于某个值的位置的迭代器，否则返回 `end`。

#### `upper_bound`

作用：查找第一个大于某个值的位置。

调用方法、提示：与 `binary_search` 类似。

返回值：找到时返回指向第一个大于某个值的位置的迭代器，否则返回 `end`。

#### `count` 与 `count_if`

##### `count`

作用：统计一个值在容器中出现的次数。

调用方法：`count(begin, end, value)`，其中 `begin` 为容器头迭代器，`end` 为尾迭代器，`value` 为需要统计的值。

提示：使用时 `value` 的数据类型必须已定义运算符 `==`。

返回值：`value` 在容器中出现的次数。

##### `count_if`

作用：统计一个值在容器中出现的次数（使用自定义比较方法）。

调用方法：`count_if(begin, end, cmp)`，其中 `begin` 为容器头迭代器，`end` 为尾迭代器，`cmp` 为比较方法。

比较方法：与 `find_if` 类似。

返回值：满足 `cmp` 条件的值出现的次数。

### 执行操作类

#### `for_each`

作用：对容器内每个值执行一次操作。

调用方法：`for_each(begin, end, func)`，其中 `begin` 为容器头迭代器，`end` 为尾迭代器，`func` 为操作。

操作：一个函数，如下所示。

```cpp
void func(Type x) {
	//do something...
}
```

这个函数有一个参数，为容器内某个值；函数的返回值为 `void`，仅包含一个参数，且数据类型（`Type`）与容器内值的数据类型相同。

返回值：无返回值。

#### `transform`

作用：对容器内每个值执行操作后放入另一个容器中（原容器不更改）。

调用方法：`transform(begin_1, end_1, begin_2, func)`，其中 `begin_1` 为被执行操作的容器的头迭代器，`end_1` 为尾迭代器，`begin_2` 为另一个容器的头迭代器，`func` 为操作。

操作：与 `for_each` 类似。

返回值：无返回值。

#### `generate`

作用：对容器内每个值设为生成器生成的值（即返回值）。

调用方法：`generate(begin, end, gen)`，其中 `begin` 为容器头迭代器，`end` 为尾迭代器，`gen` 为生成器。

生成器：一个函数，如下所示。

```cpp
Type gen() {
  //do something...
  return value;
}
```

这个函数没有参数；其中 `Type` 为数据类型，`value` 为返回值，这两个值与容器中值的数据类型相同。

返回值：无返回值。

#### `accumulate`

作用：对容器中的值求和。

调用方法：`accumulate(begin, end, init, op)`，其中 `begin` 为容器头迭代器，`end` 为尾迭代器，`init` 为求和变量的初始值（其数据类型与容器内值的数据类型相同），`op` 为实现的求和操作（当容器内值的数据类型已定义运算符 `+` 时可省略）。

关于 `op`：一个函数，如下所示。

```cpp
Type plus(Type x, Type y) {
  return x + y;
}
```

这个函数有两个参数，表示两个加数；返回值为两个加数的和。

提示：你也可以将求和操作函数换为其它操作，比如 `multiplies<Type>`（乘法操作）。

返回值：容器中值的和。

### 集合类

#### `includes`

作用：判断一个容器的内容是否是另一个容器的子序列。

调用方法：`includes(begin_1, end_1, begin_2, end_2, cmp)`，其中 `begin_1` 为容器的头迭代器，`end_1` 为尾迭代器，`begin_2` 为被判断容器的头迭代器，`end_2` 为尾迭代器，`cmp` 为比较方法。

比较方法：与 `sort` 类似。

返回值：如果是另一个容器的子序列则返回 `true`，否则返回 `false`。

#### `set_difference`

作用：求两个容器的差集（即所有在容器一中存在，但在容器二中不存在的值），并存入另一个容器中。

调用方法：`set_difference(begin_1, end_1, begin_2, end_2, and_begin, cmp)`，其中 `begin_1` 为容器一的头迭代器，`end_1` 为尾迭代器，`begin_2` 为容器二的头迭代器，`end_2` 为尾迭代器，`ans_begin` 为差集容器的头指针，`cmp` 为比较方法。

比较方法：与 `sort` 类似。

提示：与 `binary_search` 类似。

返回值：差集容器的尾指针。

#### `set_intersection`

作用：求两个容器的交集（即所有在两个容器中都存在的值），并存入另一个容器中。

调用方法、比较方法、提示：与 `set_difference` 类似。

返回值：交集容器的尾指针。

#### `set_symmetric_difference`

作用：求两个容器的对称差集（即所有在某个容器中存在但在另一个容器中不存在的值），并存入另一个容器中。

调用方法、比较方法、提示：与 `set_difference` 类似。

返回值：对称差集容器的尾指针。

#### `set_union`

作用：求两个容器的并集（即所有在某个容器中存在的值），并存入另一个容器中。

调用方法、比较方法、提示：与 `set_difference` 类似。

返回值：并集容器的尾指针。

### 最值类

#### `min`、`max`（与 `minmax`，C++11）

##### `min`

作用：找出两个值（或一个 `initializer_list`，可看做一个容器）中最小的值。

调用方法：

1. `min(a, b, cmp)`，其中 `a` 和 `b` 为需要比较的两个值，`cmp` 为比较方法（当 `a` 与 `b` 的数据类型已定义运算符 `<` 时可省略）。
2. `min(list, cmp)`，其中 `list` 为一个 `initializer_list`，`cmp` 为比较方法（当 `list` 中值的数据类型已定义运算符 `<` 时可省略）。

返回值：最小值。

##### `max`

作用：找出两个值（或一个 `initializer_list`）中最大的值。

调用方法：与 `min` 类似。

返回值：最大值。

##### `minmax`

作用：找出两个值（或一个 `initializer_list`）中最小与最大的值。

调用方法：与 `min` 类似。

返回值：一个 `pair`，其中 `first` 为最小值，`second` 为最大值。

#### `min_element`、`max_element`（与 `minmax_element`，C++11）

##### `min_element`

作用：找出容器中最小值的位置。

调用方法：`min_element(begin, end, cmp)`，其中 `begin` 为容器头迭代器，`end` 为尾迭代器，`cmp` 为比较方法（当容器中值的数据类型已定义运算符 `<` 时可省略）。

返回值：指向容器中最小值的迭代器。

##### `max_element`

作用：找出容器中最大值的位置。

调用方法：与 `min_element` 类似。

返回值：指向容器中最大值的迭代器。

##### `minmax_element`

作用：找出容器中最小值和最大值的位置。

调用方法：与 `min_element` 类似。

返回值：一个 `pair`，其中 `first` 为指向容器中最小值的迭代器，`second` 为指向容器中最大值的迭代器。

### 其它函数

#### `swap` 与 `swap_ranges`

##### `swap`

作用：交换两个值或容器中的值。

调用方法：

1. `swap(a, b)`，其中 `a` 和 `b` 为需要交换的值。
2. `swap(a_begin, b_begin)`，其中 `a_begin` 和 `b_begin` 为需要交换的容器的头迭代器。

返回值：无返回值。

##### `swap_ranges`

作用：交换两个容器中的值。

调用方法：`swap_ranges(begin_1, end_1, begin_2)`，其中 `begin_1` 为第一个容器的头迭代器，`end_1` 为尾迭代器，`begin_2` 为第二个容器的头迭代器。

返回值：无返回值。

#### `random_shuffle`（与 `shuffle`，C++11）

作用：随机打乱容器中的值（这两个函数功能都是如此）。

##### `random_shuffle`

**警告：如果您使用 C++98 以上的版本，请使用 `shuffle`。由于 `rand` 函数的生成的随机数的质量问题，`random_shuffle` 已在 C++14 中弃用，C++17 中删除。**

调用方法：`random_shuffle(begin, end, rand_func)`，其中 `begin` 为容器头迭代器，`end` 为尾迭代器，`rand_func` 为随机数生成方法（可省略，此时一般使用 `cstdlib` 库中的 `rand` 函数）。

随机数生成方法：一个函数，如下所示。

```cpp
Type rand() {
  return rand_value;
}
```

这个函数没有参数；其中 `rand_value` 为数据类型为 `Type` 的随机数，一般最大值为 `RAND_MAX`。

返回值：无返回值。

##### `shuffle`

调用方法：`shuffle(begin, end, rand_class)`，其中 `begin` 为容器头迭代器，`end` 为尾迭代器，`rand_class` 为随机数生成方法。

随机数生成方法：一个类，如下所示。

```cpp
class rand {
  public:
  Type operator ()() {
    return rand_value;
  }
}
```

这个类是一个仿函数，应定义运算符 `()`（它没有参数）；其中 `rand_value` 为数据类型为 `Type` 的随机数。

返回值：无返回值。

#### `unique` 与 `unique_copy`

**注意：从此函数开始，以下函数均有其 `_copy` 版本。`_copy` 版本的定义如下：**

```cpp
Type function([begin and end iterators...], copy_begin, [other arguments...]);
```

**其中 `copy_begin` 为拷贝容器的头迭代器。它通常在容器的头尾迭代器与其它参数之间。**

**`_copy` 版本的函数作用为将原函数计算的值复制到头迭代器为 `copy_begin` 的容器中。**

**若无特殊说明，当标题中出现函数的 `_copy` 版本时，则说明这个函数有类似于以上定义的 `_copy` 版本。这时，只会介绍普通版本。**

## 生成随机数

### C 风格随机数

### 使用 `rand()` 函数

该函数包含在 `cstdlib` 库中。

设置种子： `srand(x)`，其中 $x$ 为无符号整形类型的数（譬如 `time(NULL)`）。

产生随机数：`rand()`，范围在 $1$ 到 $2 ^ {15} - 1$ 之间。使用 `rand() % x + y` 可以生成 $y$ 到 $x + y - 1$ 之间的随机数，但是质量较差。

### 利用地址特性

`new type` 可从系统空闲内存空间得到一个新的某个 `type` 类型的地址。由于新的地址指向的内容不确定，所以我们可以利用这个特性来生成随机数。

代码：

```cpp
template<typename T>
T _rand(T x) {
	return (*(new T)) % x;
}
```

这份代码可以得到一个 $0$ 到 $x - 1$ 范围内的随机数，其数据类型为 `T`。

### C++ 风格随机数

这部分内容很快将会合并至“STL 大法教程”板块中。

---

以下内容均包含在 `random` 库内，且该库需要 C++11。

### 使用 `random_device` 类

`random_device` 类可以生成一个随机数，调用方法为 `_rand()`（其中 `_rand` 是一个 `random_device` 类）。

该类生成的随机数在不同设备上的值可能是不同的，但是在一个设备上的值是不会改变的（存疑，但原文如此）。

### 使用 `mt19937` 类

初始化与设置种子：`mt19937 _rand(x)`，其中 $x$ 为整形类型的数。

生成随机数：`_rand()`，其中 `_rand` 是一个 `mt19937` 类。生成区间内随机数类似于“ C 风格随机数”章中的“使用 `rand()` 函数”节里使用的方法。

### 使用 `uniform_int_distribution` 类

初始化与设置种子：`uniform_int_distribution<type> _rand(a, b)`，其中 `type` 为任意整数数据类型，$a$ 和 $b$ 则为 `type` 类型的数。

生成随机数：`_rand(rand_type)`，其中 `_rand` 是一个 `uniform_int_distribution` 类，`rand_type` 为随机数生成器类型（如 `mt19937`，但一定要先定义该类型的变量）。它可以生成 $a$ 到 $b$（这两个常量已经在上文中提到过）之间的随机数。

### 使用 `uniform_real_distribution` 类

使用方法类似于 `uniform_int_distribution` 类，但是 $a$ 和 $b$ 为任意小数数据类型，生成的随机数也为一个小数随机数。

## Better ConsolePauser

### ConsolePauser 是什么？

`ConsolePauser.exe` 是 DevC++ 等众多主流 C++ 便携式 IDE 在运行程序时给程序套的一层“壳”，在程序运行完后显示程序运行时的一些信息。

### 那为什么要写这个项目？

原本的 `ConsolePauser.exe` 界面显示的内容不全面，且缺乏 Oier 需要的内容，本项目因此而来。

### 使用方法

#### 编译

编译时记得加上 `-lpsapi`，否则可能无法正常编译。

如 DevC++，点击“工具——编译选项”，勾选“编译时加入以下命令”，在下方输入框中加入 `-lpsapi` 即可。

#### 使用

将程序编译后重命名为  `ConsolePauser.exe`，随后放入 IDE 安装目录中替换原来的程序。

此时使用 IDE 运行程序，应该就能正常使用 `Better ConsolePauser` 了。

double GetProcessCpuUsage(HANDLE hProcess, unsigned long long* lpKernelTime, unsigned long long* lpUserTime) {
	FILETIME createTime, exitTime, kernelTime, userTime;
	if (!GetProcessTimes(hProcess, &createTime, &exitTime, &kernelTime, &userTime)) {
		return 0.0;
	}
	
	unsigned long long kt = ((unsigned long long)kernelTime.dwHighDateTime << 32) | kernelTime.dwLowDateTime;
	unsigned long long ut = ((unsigned long long)userTime.dwHighDateTime << 32) | userTime.dwLowDateTime;
	
	if (lpKernelTime && lpUserTime) {
		unsigned long long deltaK = kt - *lpKernelTime;
		unsigned long long deltaU = ut - *lpUserTime;
		*lpKernelTime = kt;
		*lpUserTime = ut;
		
		static unsigned long long lastSysTime = 0;
		FILETIME sysIdle, sysKernel, sysUser;
		GetSystemTimes(&sysIdle, &sysKernel, &sysUser);
		unsigned long long sysTotal = 
		((unsigned long long)sysKernel.dwHighDateTime << 32) | sysKernel.dwLowDateTime +
		((unsigned long long)sysUser.dwHighDateTime << 32) | sysUser.dwLowDateTime;
		
		if (lastSysTime == 0) {
			lastSysTime = sysTotal;
			return 0.0;
		}
		unsigned long long deltaSys = sysTotal - lastSysTime;
		lastSysTime = sysTotal;
		
		if (deltaSys == 0) return 0.0;
		return (double)(deltaK + deltaU) / (double)deltaSys * 100.0;

	return 0.0;

			vt __t;
			while (_n != 0) {
				__t = _m % _n;
				_m = _n;
				_n = __t;
			}
			return _m;
		}
	public:
	// constructor
		vt x, y;
		_frac() : x(1), y(1) { }
		_frac(const vt _x, const vt _y) : x(_x), y(_y) { assert(x > 0 && y > 0); }
		_frac(const _frac& _f) : x(_f.x), y(_f.y) { assert(x > 0 && y > 0); }
		_frac reset(const vt _x, const vt _y) {
			assert(_x > 0 && _y > 0);
			x = _x, y = _y;
			return *this;
		}

			return reset(_f.x, _f.y);
		}

			return reset(_f);
		}

			vt __g = get_gcd(x, y);
			return _frac(x / __g, y / __g);
		}
		_frac rof() {
			return reset(get_rof());
		}

			return y / get_gcd(y, _f.y) * _f.y;
		}
		_frac get_roftcd(vt _m) {
			return _frac(x * _m, y * _m);
		}

			return reset(get_roftcd(_m));
		}

			vt __lcd = get_lcd(_f);
			return _frac(__lcd / y * x, __lcd);

			return reset(get_roftcd(_f));
		}

			return std::make_pair(get_roftcd(_f), _f.get_roftcd(*this));
		}

			std::pair<_frac, _frac> __p = get_all_roftcd(_f);
			reset(__p.first), _f.reset(__p.second);
